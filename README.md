# Green Kolkata — Urban Parks & Biodiversity

Interactive GIS story map of selected green and blue spaces across Greater Kolkata.

## Data and analysis
- Sentinel-2 based NDVI, green-cover and water analysis (2025)
- Landsat 8/9 land-surface-temperature analysis (2025)
- Site-wise ecological metrics from the exported GEE CSV
- Interactive site photographs and satellite views
- NDVI, green cover, water and LST raster layers are generated for the published site from the exported GeoTIFF files
